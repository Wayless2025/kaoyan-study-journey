## 记录说明

<details>
<summary>成绩、用时与日期如何统计</summary>

- **成绩依据**：沿用作品原标题。政治只记录选择题成绩；英语题数与分数分别标明，不混用。
- **用时**：只记录原标题写明的用时，不用发布时间推算；政治和英语不设用时列。
- **年份**：表中的年份是试卷年份或模拟卷标注年份。
- **发布日**：来自作品发布日期，按北京时间展示，不作为实际作答日期。
- **缺项**：未记录用“—”或“未记录”表示，不当作零分；英语未做齐四篇时只统计已有题目。
- **原始内容**：各图片目录保留完整原标题、来源链接、发布日期与图片顺序，笔记及批注保持原样。

</details>
