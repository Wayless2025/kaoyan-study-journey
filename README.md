# 考研刷题与模考记录

记录政治、英语一、数学和408的真题练习、模拟考试与复盘图片，也保留备考中的报名与感想。

[政治](%E6%94%BF%E6%B2%BB/) | [英语一](%E8%8B%B1%E8%AF%AD%E4%B8%80/) | [数学](%E6%95%B0%E5%AD%A6/) | [408](408/) | [历程记录](%E5%8E%86%E7%A8%8B%E8%AE%B0%E5%BD%95.md)

共归档 **147篇作品、456张图片**。来源为本人抖音账号“承重”的已发布作品，图片保持下载时的文件内容与顺序。

成绩与用时依据原标题。政治记录选择题成绩；英语阅读、完形和新题型记录答对题数，翻译记录得分。政治和英语不设用时列。数学与408未写用时的标为“未记录”。

数学真题按数学一、数学二、数学三分类，模拟题按年份、老师／机构和卷次分类；另保留学习记录。仅数三表格列出适用满分。数三标题如 `145-5` 表示剔除未学知识点后适用满分145分、扣5分，即实际得分140分；原标题仍完整保留。

目录中的年份是试卷年份／模拟卷标注年份。各文件夹记录的发布日是北京时间的作品发布日期，不作为实际作答日期；同年英语四篇阅读可能分次完成。
